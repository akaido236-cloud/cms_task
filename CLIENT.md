SD Media - Project Overview
Welcome to the SD Media website project! This document serves as a guide for clients to understand the project.

Features Implemented
Multilingual Support (i18n): The site supports both English and Arabic out of the box.
SEO Optimized: Metadata, OpenGraph tags, and semantic HTML are used to rank high on Google.
Creative Design & Animations: Built with Framer Motion. The black, gold, and silver theme matches your brand identity perfectly.
Fully Responsive: Looks great on desktop, tablet, and mobile.
How to change text/content?
All text content is stored in the messages/ folder.

To edit English text, open messages/en.json.
To edit Arabic text, open messages/ar.json.
How to change images?
Place your images in the public/ folder. The main logo is located at public/logo.jpeg.
